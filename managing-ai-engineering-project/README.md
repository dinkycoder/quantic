# Managing AI Engineering Project: Lily's Florist

This is the requirements package for Lily's Florist, an established flower shop that wants an AI-enabled website. It covers online ordering, inventory management and a 24/7 customer-support assistant.

| File | Contents |
|---|---|

| `Lilys-Florist-Requirements-Package.docx` | Editable source of the PDF |
| `wireframes/` | Annotated mobile wireframes exported from Figma (screens 1–6) |
